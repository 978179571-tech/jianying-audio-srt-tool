# 配音与字幕整理

Windows 桌面工具：读取剪映草稿中的独立朗读配音，按逐行文案重新排列，清理每段首尾多余静音，输出配音 WAV 与连续显示的 SRT。

## 下载使用

在本仓库的 **Releases** 页面下载 Windows 压缩包，解压后双击 `配音字幕整理-v1.1.exe`。不需要安装 Python 或 .NET。

音频处理需要本机提供 `ffmpeg.exe`。程序会尝试寻找剪映安装目录或 PATH 中的 FFmpeg；找不到时在“设置”中手动选择。下载包未附带 FFmpeg。

## 工作流程

1. 选择包含 `draft_content.json` 的单个剪映草稿文件夹。
2. 核对找到的配音组，粘贴或导入 TXT 文案：**一行一条字幕**。
3. 点击“按这份文案匹配配音”，再生成试听。
4. 逐句试听、整段试听或试听两句衔接，按需调整停顿与语速。
5. 导出 WAV 与连续 SRT。将配音放到剪映时间线零秒，再导入 SRT，无需重新朗读。

## 功能

- 使用现有音色；默认保留原始语速。
- 按文案顺序消除片段之间的重叠。
- 仅清理每段音频首尾静音，保留片段内部停顿与呼吸声。
- 按文案分行合并完整朗读片段，输出保留输入文字。
- 句间停顿可设为 0～3000 毫秒；同一行内多个音频的接缝停顿可调整。
- 各行语速支持 0.75～1.50 倍。
- 支持“全选”按钮、Ctrl+A、多选批量调整；只改变停顿时保留各行语速。
- 字幕从零秒开始，上一条结束时间等于下一条开始时间，中间无断档。
- 保存及恢复整理方案，每次导出新建文件夹。
- 本地处理，原草稿和原始音频保持不变。

## 兼容范围与限制

- 支持可读取的剪映 JSON 中的独立“文本朗读”音频，包括复合片段内嵌数据。
- 不解密主草稿，不读取 `.bak` 备份。主稿加密但有可读复合片段时，需要核对该组内容是否为本次使用的版本。
- 支持多个完整音频片段合为一行；换行落在一个片段内部时会提示先拆分朗读，不会按字数猜切点。
- 不恢复已经混合在同一音频中的重叠语音，不自动去除句内呼吸声。
- 文案需与配音文字和顺序一致。可兼容 D3 / D₃ 等字符写法，无法自动修正文案与实际朗读内容的差异。
- 整理后总时长随配音变化，不保证与原视频长度一致。

完整操作说明见 [使用说明.md](使用说明.md)，通用示例见 [examples/script.txt](examples/script.txt)。

## 从源码运行

Windows，Python 3.10+（包含 Tkinter）。运行时 Python 代码仅使用标准库，另需本地 FFmpeg。

```powershell
python app.py
```

## 测试

```powershell
python -m unittest -v test_engine test_app
```

可选真实草稿集成测试：设置 `CCJ_TEST_DRAFT` 为草稿文件夹，`CCJ_TEST_SCRIPT` 为与其匹配的逐行 TXT 文案。测试会在临时文件夹生成结果，所有输入保留在本机。

## 打包 Windows 程序

```powershell
python -m pip install -r requirements-build.txt
.\build.ps1
```

程序生成于 `dist`，构建依赖与第三方 FFmpeg 均不提交到源码仓库。

本仓库不包含实际业务草稿、配音素材、个人方案和本机设置。
